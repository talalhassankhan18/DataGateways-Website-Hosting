# assets/media

The six hero plates here are **original SVG artwork**, generated by `scripts/generate-hero-art.mjs`
(`npm run art:generate`). They are committed, deterministic, and carry no third-party licence —
there is nothing to clear and nothing to buy.

Each plate is paired with a matching animated canvas variant in `apps/web/src/lib/backdrop.ts`
drawing the same composition, so the still paints immediately as the LCP element and the motion
layer takes over without the hero appearing to change picture.

| File | Variant | Page |
| --- | --- | --- |
| `hero-home.svg` | `network` | Home |
| `hero-about.svg` | `lattice` | About |
| `hero-platform.svg` | `circuit` | Platform |
| `hero-datanerve.svg` | `cipher` | DataNerve |
| `hero-ainerve.svg` | `signal` | AINerve |
| `hero-contact.svg` | `architecture` | Contact |

## Why these are drawn rather than sourced

The brief asked for royalty-free stock footage. The free tiers of the reachable stock libraries
carry nothing that fits: their abstract and "cyber" clips are paywalled, and what remains is
lifestyle footage full of recognisable faces and third-party product UI — both barred by
`docs/design-reference.md`. Stock dashboard footage also reads as fake on a security vendor's site.
Drawing the plates solved the licensing question outright and costs kilobytes instead of megabytes.

## Optional video

The heroes do not need video. If the client supplies licensed footage, drop it in with one of these
names and that hero starts using it automatically — no code change:

| Filename | Notes |
| --- | --- |
| `hero-home.mp4` / `.webm` | 8–15s loop, muted, no audio track, ≤ 4 MB compressed |
| `hero-about.mp4` / `.webm` | Same spec, visually distinct from home |

Source from Pexels, Coverr, Pixabay or Mixkit — **never from dtv.sa**, whose footage is licensed to
them. Keep every clip dark and low-contrast so white display type stays legible, with no
recognisable faces and no third-party trademarks.

```bash
ffmpeg -i in.mp4 -vcodec libx264 -crf 30 -an hero-home.mp4
```

**Every file added here needs a row in `docs/licences.csv`.** No row, no ship.
